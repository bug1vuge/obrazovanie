# Study Pro — подготовка к ОГЭ и ЕГЭ

Кликабельный MVP образовательной платформы: каталог курсов по школьным предметам, личный
кабинет ученика с выбором экзамена и курса, кабинет преподавателя с конструктором курсов и
статистикой дохода, админ-панель модерации.

Данные статичны (демо-база генерируется детерминированно и хранится в `localStorage`
браузера), поэтому прототип работает без сервера и подходит для показа инвесторам.

**Демо:** https://bug1vuge.github.io/obrazovanie/

Промокоды для оплаты: `EGE2026` (−20%), `OGE15` (−15%), `START10` (−10%). Оплата имитируется.
Кнопка «Сбросить демо-данные» в настройках профиля возвращает исходное состояние.

## Стек

- React 19 + TypeScript (strict) + Vite
- React Router 7 (hash-роутинг — работает на GitHub Pages без настройки сервера)
- Zustand 5 (состояние и персистентность), Tailwind CSS 3
- Vitest + Testing Library (юнит- и интеграционные тесты)
- ESLint 9, Prettier, GitHub Actions (проверки и деплой на GitHub Pages)

## Запуск

```bash
npm ci
npm run dev          # http://localhost:5173
npm test             # все тесты
npm run lint         # ESLint
npm run typecheck    # проверка типов
npm run build        # production-сборка в dist/
```

Требуется Node.js 22 (см. `.nvmrc`).

## Архитектура

Код разложен по слоям в духе Feature-Sliced Design — зависимости идут только сверху вниз:

```
src/
  app/        точка входа, роутинг, ErrorBoundary, глобальные стили
  pages/      экраны: каталог, курс, урок, кабинет, редактор курса, админка, сертификат
  widgets/    крупные блоки экранов: шапка и навигация, карточка курса, кабинет ученика/преподавателя
  features/   пользовательские сценарии: вход, фильтры каталога, оплата, тест, отзыв, сертификат
  entities/   доменная модель (types.ts) и чистые функции предметной области
  store/      Zustand-стор: срезы (auth, learning, studio, admin), селекторы, guards
  data/       генератор демо-данных: предметы, преподаватели, каталог, продажи
  shared/     UI-kit, графики, утилиты форматирования
```

Ключевые решения:

- **Доменные операции — в сторе, а не в компонентах.** Запись на курс, прогресс, тесты,
  конструктор курсов и модерация реализованы как действия стора с проверкой прав
  (`store/slices/guards.ts`) и понятными ошибками (`DomainError`). Компоненты только вызывают их.
- **Чтение — через чистые селекторы** (`store/selectors.ts`): программа курса, прогресс,
  статистика преподавателя и платформы. Их легко тестировать и переиспользовать.
- **Данные нормализованы** (`Record<id, entity>`), формы сущностей совпадают с будущим API —
  при подключении бэкенда меняется слой стора, а не UI.
- **Детерминированный сид** (`data/seed.ts`): одинаковые цифры у всех посетителей и в тестах.
  У каждого курса своя обложка, повторов нет (это проверяется тестом).

## Изменения относительно исходного макета

1. Фильтры каталога: убраны цена и сортировка «Популярные»; фильтр уровня заменён на экзамен —
   только ОГЭ и ЕГЭ.
2. Нижняя навигация: только «Каталог» и «Профиль»; обучение и студия перенесены в личный кабинет
   (старые адреса `/my` и `/studio` перенаправляют туда).
3. Кабинет ученика начинается с выбора экзамена (ОГЭ/ЕГЭ) и курса; выбор сохраняется в профиле.
4. Кабинет преподавателя: вкладка «Статистика» — доход с продаж, к выплате, продажи, средний чек,
   ученики, доход по месяцам и по курсам, последние продажи.
5. Уникальные обложки для каждого из курсов (фото Unsplash).

## Деплой

Workflow `.github/workflows/ci.yml` на каждый push и pull request запускает форматирование,
линтер, проверку типов, тесты и сборку. Пуш в `main` дополнительно публикует сборку на
GitHub Pages (Settings → Pages → Source: GitHub Actions).
